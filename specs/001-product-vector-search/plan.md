# Implementation Plan: Product Management with pgvector Semantic Search

**Branch**: `001-product-vector-search` | **Date**: 2026-05-18 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/001-product-vector-search/spec.md`

## Summary

Build a FastAPI + PostgreSQL (Prisma ORM) product management system for a shopping-mall/ERP domain.
Products have rich retail attributes (SKU, price tiers, dimensions, stock, tags, images, SEO fields).
On every INSERT/UPDATE, a PostgreSQL trigger fires `pg_notify` to a Python embedding worker that
generates a 384-dim vector via `sentence-transformers` and upserts it into `product_embeddings`.
A `/api/v1/products/search` endpoint performs cosine-similarity search via `pgvector`'s `<=>` operator.

## Technical Context

**Language/Version**: Python 3.11+

**Primary Dependencies**:
- `fastapi>=0.110`, `uvicorn[standard]`
- `prisma` (Prisma Client Python, asyncio interface)
- `asyncpg` (LISTEN/NOTIFY channel for embedding worker)
- `sentence-transformers>=2.6` (embedding model)
- `pydantic-settings` (env config)
- `httpx` (async test client)
- `pytest>=8`, `pytest-asyncio`, `anyio`

**Storage**: PostgreSQL ≥ 15 with `pgvector` extension; single DB instance

**Testing**: `pytest` with `pytest-asyncio` + `httpx.AsyncClient`

**Target Platform**: Linux server / Docker container; local dev via Docker Compose

**Project Type**: Web service (REST API)

**Performance Goals**:
- Product CRUD: < 200ms p95
- Vector search (10k products): < 500ms p95
- Embedding generation: < 2s per product (async, non-blocking)

**Constraints**:
- Embedding must not block HTTP response (async worker via pg_notify)
- No authentication in v1
- No external queue (Celery/Redis) in v1

**Scale/Scope**: Up to 100k products for v1; ivfflat index with lists=100

## Phase 1: Design & Contracts (COMPLETE)

See [data-model.md](./data-model.md), [contracts/](./contracts/), [quickstart.md](./quickstart.md).

**Entities**: Product (25+ fields), ProductEmbedding, Category (tree), Brand

**Key design decisions**:
- `ProductEmbedding.embedding` uses `Unsupported("vector(384)")` in Prisma — queried via `query_raw`
- `ivfflat` index with `lists=100` for ANN search
- Embedding source text: `{name} {brand} {category} {description} {tags}`
- `pg_notify` is the atomic bridge between DB trigger and Python worker
- FastAPI lifespan manages asyncpg connection lifecycle

**Contracts defined**:
- `POST /api/v1/products` → 201 / 422 / 409
- `GET /api/v1/products` → 200 (paginated)
- `GET /api/v1/products/{id}` → 200 / 404
- `PATCH /api/v1/products/{id}` → 200 / 404 / 409
- `DELETE /api/v1/products/{id}` → 204 / 404
- `GET /api/v1/products/sku/{sku}` → 200 / 404
- `POST /api/v1/products/search` → 200 / 422
- `GET /health` → 200 / 503
